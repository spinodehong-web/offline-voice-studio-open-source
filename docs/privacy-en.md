# Privacy policy — Offline Voice Studio

[简体中文](privacy.md) · Updated November 1, 2026 · 2.5 build253 store candidate

Processing stays on your Mac
Speech generation, recognition, project editing and audio processing run locally. The application does not automatically upload your drafts, recordings, voice references, project files or diagnostic logs. It has no cloud synthesis fallback, advertising SDK or analytics service. This build does not request network client or server entitlements.

Local profiles
A local profile is a workspace name, not a verified identity or online account. No email address, password or telephone number is required. Profile names, the last selected profile and interface-language preferences are saved on this Mac. Drafts, tasks, projects and recordings are stored separately for each profile. Bundled models and the 35 confirmed voices are shared. Existing data remains in the default profile without being moved or deleted.
Profiles are not a security boundary within the same macOS account. They do not provide password protection, purchase verification, anti-copying, cloud synchronization or remote password recovery. Files that you save outside the application remain in the locations you select.

Local files and diagnostics
Local recovery records and logs may contain draft fragments, project identifiers and file paths. They are used for on-device recovery and troubleshooting and are not automatically transmitted. You control which documents the native file picker opens and where exports are saved. Original audio and edit history may be retained to support undo, redo and recovery; a WAV export is not a complete project backup.

External services
You can choose to open public support and privacy links in your browser. GitHub and Apple operate their own services under their own privacy terms. Apple may separately handle store downloads, purchases and any reports you choose to share with Apple. Voluntary public support posts are not private: do not post confidential text, recordings, projects, passwords or verification codes.

Your choices
Keep backups before important edits or moving to another Mac. This build has no automatic cloud account deletion or data-transfer service because it has no cloud account. The profile interface does not delete profile data. To request guidance about local data, use the support page without attaching private material.

Our documentation text embeds no tracking pixels, analytics, third-party fonts or upload forms; GitHub's surrounding interface is separately operated by GitHub. To request removal of accidentally posted information, submit a request without repeating sensitive content. Uninstalling the app alone does not erase all local projects, history or system backups. This app does not request camera, location, contacts or live microphone access; reference files are selected locally. Privacy handling will be updated before any future cloud or upload feature is introduced.
